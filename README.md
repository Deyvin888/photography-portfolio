# Photography Portfolio

A modern, responsive photography portfolio built to showcase my landscape, hiking, wildlife, and travel photography.

This project is currently under active development as I continue learning web development and is a personal side project. The goal is to create a clean and fast website that highlights my work while providing an enjoyable viewing experience across all devices.

---

## Project Goals

* Showcase my photography in a professional gallery
* Create a minimal, distraction-free viewing experience
* Learn modern web development by building a real project
* Optimise performance for fast image loading
* Display low resolution images with watermarks to prevent transmission
* Deploy the website to a custom domain
